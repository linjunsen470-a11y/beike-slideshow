# 本地历史归档说明

项目曾积累多轮模板实验、任务说明、预览图和审阅报告。这些内容仅用于追溯，不参与运行，也不是当前操作指令。项目背景与调用方法见 [README](../README.md)。

当前仓库只提交本说明。历史压缩包被 Git 忽略，仅在维护机器上保留，因此新克隆的仓库没有这些包，也不需要它们才能运行。

| 本地历史内容 | 用途 |
| --- | --- |
| `history-before-cleanup-20261029.zip` | 旧任务、报告、模板演进说明、审阅脚本和旧测试脚本；包含清理时的维护记录 |
| `audio.zip` | 原始音频打包文件；运行时使用解压后的 `bgm/` |
| 对应房源目录中的 `review-history-*.zip` | 该房源较旧的预览、时间线及审阅日志 |

需要追溯时按需解压到独立位置。不要将旧说明中的具体房源编号、绝对路径、默认参数或密钥处理方式直接用于当前任务，也不要用归档脚本替换当前入口。
